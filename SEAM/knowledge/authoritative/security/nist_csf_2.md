# NIST Cybersecurity Framework 2.0

Engineering use:
- Treat cybersecurity as a risk-management activity, not a single feature.
- Make security outcomes visible in design, implementation, QA, and delivery.
- Use governance, identification, protection, detection, response, and recovery as planning prompts for sensitive systems.

SEAM application:
- Planning should identify security-sensitive assets, actors, and workflows.
- QA should verify that sensitive actions have controls and traceability.
- Delivery should preserve security assumptions and residual risks in artifacts.
