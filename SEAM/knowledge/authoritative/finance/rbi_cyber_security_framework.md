# RBI Cyber Security Framework For Banks

Engineering use:
- Finance systems should treat cyber security as an explicit governance and operational concern.
- Security monitoring, resilience, architecture controls, and risk-based controls matter for financial systems.
- Sensitive financial systems should preserve auditability and operational traceability.

SEAM application:
- Finance project planning should include audit logs, authorization boundaries, and transaction integrity.
- QA should test ownership checks and sensitive report access.
- Delivery should document security assumptions and residual risks.
