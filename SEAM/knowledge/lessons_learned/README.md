# Lessons Learned

Description: Validated engineering lessons from QA, delivery, and user feedback.

Principles:
- Lessons must be actionable and sanitized.
- Pending lessons should not influence normal retrieval.
- Validate a lesson after the fix is confirmed.

Recommended practices:
- Include the problem, cause, fix, and prevention.
- Add tags for affected technology and category.

Common mistakes:
- Storing speculative model output as a validated lesson.
