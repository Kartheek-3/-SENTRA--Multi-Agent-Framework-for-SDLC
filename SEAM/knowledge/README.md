# SEAM Knowledge Repository

This repository contains curated software-engineering knowledge for SEAM agents. Documents are intentionally concise, validated, and safe for retrieval. They guide analysis, planning, coding, QA, and delivery without retraining the LLM.

Principles:
- Use validated knowledge only for normal retrieval.
- Prefer small, relevant chunks over broad context dumps.
- Keep sensitive project details out of reusable knowledge.
- Treat GitHub findings as optional reference, not source code to copy.

Common mistakes:
- Indexing raw project secrets.
- Storing entire external repositories.
- Using pending or unvalidated lessons in normal workflows.
