# React Quick Start

Engineering use:
- Build UI from components with clear data flow.
- Keep state close to the component or workflow that owns it.
- Use conditional rendering and list rendering deliberately.

SEAM application:
- Generated React projects should use components for repeated UI surfaces.
- API data should be loaded through predictable state transitions.
- Forms should show validation feedback while still relying on backend validation for security.
