# AWS Well-Architected Framework

Engineering use:
- Evaluate cloud workloads for security, reliability, operational excellence, performance, cost, and sustainability.
- Treat architecture review as a constructive design practice, not a one-time audit.

SEAM application:
- Planning should avoid unnecessary cloud complexity for small projects.
- Larger projects should record reliability, security, and operational tradeoffs in design artifacts.
