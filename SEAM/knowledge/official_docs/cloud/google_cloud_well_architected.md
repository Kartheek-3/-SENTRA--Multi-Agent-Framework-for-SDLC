# Google Cloud Well-Architected Framework

Engineering use:
- Document architecture decisions and design for change.
- Prefer simplicity and managed services where they reduce operational burden.
- Consider security, reliability, operations, performance, cost, and sustainability.

SEAM application:
- Planning should explain why architecture complexity is needed.
- Delivery artifacts should preserve deployment assumptions and operating requirements.
