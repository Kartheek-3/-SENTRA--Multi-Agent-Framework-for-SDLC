# Reusable Code Guidance

Description: Rules for reusing patterns without blindly copying code.

Principles:
- Reuse small internal helpers when they are understood and tested.
- External repositories may inspire structure, but source code must not be copied automatically.
- Keep attribution and license review when reuse occurs.

Recommended practices:
- Prefer templates for common API and project structure.
- Validate generated helper code with tests.

Common mistakes:
- Copying code without license review.
- Reusing code that does not fit the requirement.
